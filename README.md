# Cloud Monitoring Project

## Overview
This project demonstrates cloud-based application monitoring using AWS CloudWatch (simulated setup).

## Objective
To monitor system performance and define alerts for key metrics like CPU, Memory, and Disk usage.

---

## Metrics Monitored
- CPU Utilization
- Memory Utilization
- Disk Usage
- Network Traffic

---

## Alert Rules
- CPU Usage > 80%
- Memory Usage > 85%
- Disk Usage > 90%
- Network Latency > 2s

---

## Dashboard (Simulated)
The dashboard includes:
- Real-time CPU graph
- Memory usage graph
- Disk usage graph
- Network traffic visualization

---

## Architecture
User Application → Cloud Monitoring Agent → CloudWatch → Alerts → Email Notification

---

## Tools Used
- AWS CloudWatch (conceptual)
- GitHub
- Monitoring Concepts (DevOps)

---

## Outcome
Successfully designed a cloud monitoring system with alerts and dashboard visualization.
